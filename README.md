# Network Reconnaissance & Port Scanning Audit

## Project Overview
This repository documents Task 03 for the RabTech Academy Cybersecurity & Ethical Hacking course.

## Objectives
- Perform authorized network reconnaissance.
- Document TCP SYN and UDP scan results.
- Identify services and versions where permitted.
- Record operating-system detection results where available.
- Analyze network traffic using Wireshark.
- Document findings, risks, and recommendations.

## Scope and Authorization
Scanning must be limited to the sandbox host explicitly authorized for this task. Confirm the target and testing boundaries before running scans.

## Deliverables
- Network audit report in PDF format.
- Nmap scan outputs.
- Wireshark packet-analysis screenshots.
- Open-port and service inventory.
- Findings, risk assessment, and remediation recommendations.

## Evidence Integrity
All scan results and screenshots will be collected from the authorized lab. No results will be fabricated.

Documentation setup in progress.
